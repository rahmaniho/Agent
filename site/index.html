      جلسه ایجنت

      این بخش فقط با سرور محلی اختیاری Agent Studio و FCC نصب‌شده روی همان دستگاه کار می‌کند. ایجنت ممکن است فایل‌ها را تغییر دهد یا دستور اجرا کند؛ فقط در پروژه‌ای که به آن اعتماد دارید استفاده کنید.

      در حال بررسی اتصال محلی...

      برای تأیید درخواست‌های دسترسی و امکانات کامل، از رابط Admin محلی FCC استفاده کنید.

      شروع در چند قدم

      این وب‌اپ راهنماست و به‌تنهایی مدل یا سرور FCC را اجرا نمی‌کند. برای استفاده، FCC را روی دستگاه خود نصب و پیکربندی کنید.

      1. ۱
        نصب Free Claude Code

        طبق راهنمای رسمی، نصب‌کننده مناسب سیستم‌عامل خود را اجرا کنید و حداقل یک ایجنت انتخاب کنید.

        مشاهده راهنمای نصب رسمی ↗
      2. ۲
        اجرای سرور و تنظیم ارائه‌دهنده

        در لینوکس دستور زیر را اجرا کنید؛ در ویندوز و مک برنامه را از منوی برنامه‌ها باز کنید. سپس در Admin UI ارائه‌دهنده و کلید خود را تنظیم کنید.

        fcc-server
      3. ۳
        اجرای ایجنت

        پس از پیکربندی مدل، ایجنت نصب‌شده را از ترمینال اجرا کنید؛ برای مثال:

        fcc-claude
      ⌘

      ساخته شده برای انعطاف

      پشتیبانی از چندین ایجنت و ارائه‌دهنده، با امکاناتی مثل fallback و کنترل محدودیت درخواست.

      Claude CodeCodexOpenCode

      دسترسی و محدودیت پلن‌های رایگان به ارائه‌دهنده بستگی دارد و ممکن است تغییر کند. کلیدهای API خود را فقط در محیط امن FCC وارد کنید.

                خانه/نصب

                نصب و شروع

                سه قدم تا اجرا. برای هر هارنس (Claude Code، Codex، Cursor، OpenCode، Gemini، Zed، Copilot، …) هدف نصب جدا وجود دارد.

                1. کلون ریپو (یا نصب به‌عنوان پلاگین Claude Code).
                2. پروفایل: minimal برای context سبک، developer برای کار روی کد، full برای همه‌چیز. hookها تصمیم صریح می‌خواهند: --enable-hooks یا --no-hooks.
                3. مسیر خدمت را باز کن و پرامپت‌های همان کار را اجرا کن.
