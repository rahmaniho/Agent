      ابزار متن‌باز

      Free Claude Code

      ایجنت کدنویسی خود را به ارائه‌دهندگان مدل متصل کنید. سورس کامل پروژه در پوشه free-claude-code/ این مخزن قرار دارد.

      فضای اجرای محلی · CODEX

      استودیوی ایجنت

      یک جلسه بسازید یا کار قبلی خود را ادامه دهید.

      در حال بررسی
      i

      ایجنت می‌تواند فایل‌ها را تغییر دهد یا دستور اجرا کند. این اتصال فقط روی دستگاه خودتان و با فعال‌سازی صریح کار می‌کند؛ برای درخواست‌های دسترسی از Admin خود FCC استفاده کنید.

      راهنمای فعال‌سازی اتصال محلی

      ابتدا FCC و Codex را نصب کنید، ارائه‌دهنده و مدل را در Admin تنظیم کنید و fcc-server را اجرا کنید. سپس از ریشه مخزن، دستور زیر را در ترمینال دیگری اجرا و آدرس نمایش‌داده‌شده را در مرورگر همان دستگاه باز کنید.

      node site/serve.mjs --host 127.0.0.1 --port 4173 --fcc-local

      این قابلیت در نسخه میزبانی‌شده روی Vercel فعال نیست. تأییدهای ایجنت در Admin خود FCC انجام می‌شود.

      جلسه‌های اخیر

      تا ۲۵ جلسه اخیر در FCC

      پس از اتصال نمایش داده می‌شود.

      ✳آماده برای ساختن؟

      یک جلسه جدید بسازید یا یکی از جلسه‌های اخیر را انتخاب کنید.

      جلسه فعال

      برای تأیید درخواست‌های دسترسی و تنظیم مدل، از رابط Admin محلی FCC استفاده کنید.

      شروع در چند قدم

      این وب‌اپ راهنماست و به‌تنهایی مدل یا سرور FCC را اجرا نمی‌کند. برای استفاده، FCC را روی دستگاه خود نصب و پیکربندی کنید.

      1. ۱
        نصب Free Claude Code

        طبق راهنمای رسمی، نصب‌کننده مناسب سیستم‌عامل خود را اجرا کنید و حداقل یک ایجنت انتخاب کنید.

        مشاهده راهنمای نصب رسمی ↗
      2. ۲
        اجرای سرور و تنظیم ارائه‌دهنده

        در لینوکس دستور زیر را اجرا کنید؛ در ویندوز و مک برنامه را از منوی برنامه‌ها باز کنید. سپس در Admin UI ارائه‌دهنده و کلید خود را تنظیم کنید.

        fcc-server
      3. ۳
        اجرای ایجنت

        پس از پیکربندی مدل، ایجنت نصب‌شده را از ترمینال اجرا کنید؛ برای مثال:

        fcc-claude
      ⌘

      ساخته شده برای انعطاف

      پشتیبانی از چندین ایجنت و ارائه‌دهنده، با امکاناتی مثل fallback و کنترل محدودیت درخواست.

      Claude CodeCodexOpenCode

      دسترسی و محدودیت پلن‌های رایگان به ارائه‌دهنده بستگی دارد و ممکن است تغییر کند. کلیدهای API خود را فقط در محیط امن FCC وارد کنید.

                خانه/نصب

                نصب و شروع

                سه قدم تا اجرا. برای هر هارنس (Claude Code، Codex، Cursor، OpenCode، Gemini، Zed، Copilot، …) هدف نصب جدا وجود دارد.

                1. کلون ریپو (یا نصب به‌عنوان پلاگین Claude Code).
                2. پروفایل: minimal برای context سبک، developer برای کار روی کد، full برای همه‌چیز. hookها تصمیم صریح می‌خواهند: --enable-hooks یا --no-hooks.
                3. مسیر خدمت را باز کن و پرامپت‌های همان کار را اجرا کن.

                هارنس‌های پشتیبانی‌شده
