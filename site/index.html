          شروع

          سه قدم تا اجرا

          1. کلون ریپو (یا نصب به‌عنوان پلاگین Claude Code).
          2. پروفایل را انتخاب کن: minimal برای context سبک، developer برای کار روی کد، full برای همه‌چیز. hookها تصمیم صریح می‌خواهند: --enable-hooks یا --no-hooks.
          3. مسیر خدمت را از بالا باز کن و پرامپت‌های همان کار را اجرا کن.

          برای هارنس‌های دیگر: --target cursor، opencode، gemini، zed، copilot، qwen، kimi و …

          git clone https://github.com/affaan-m/ecc.git && cd ecc
          ./install.sh --profile developer --target claude
          ./install.sh --target claude --skills tdd-workflow,api-design,design-system

          بدون نصب هم می‌توانید هر skills/<name>/SKILL.md را مستقیم استفاده کنید.
