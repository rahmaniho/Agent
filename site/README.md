# ECC Playbook — وب‌اپ راهنمای «چه چیزی برای چه کاری»

وب‌اپ فارسی/RTL که کاتالوگ ریپوی [affaan-m/ecc](https://github.com/affaan-m/ecc) را به **نیاز واقعی بازدیدکننده** نگاشت می‌کند.
برای هر خدمت (ساخت سایت، داشبورد، API، امنیت، کارایی، ایجنت، …) مسیر گام‌به‌گام، ابزارهای مربوطه و **پرامپت‌های آماده برای کپی** را نشان می‌دهد.

وب‌اپ استاتیک بدون نیاز به build هنگام اجرا؛ کد Supabase برای مرورگر از پیش bundle شده و برای بازسازی آن به npm نیاز است.

**آنلاین:** <https://rahmaniho.github.io/Agent/>

## اجرا در محل

```bash
node site/serve.mjs              # http://localhost:4173
node site/serve.mjs --port 8080
```

یا هر سرور استاتیک دیگر با ریشهٔ `site/`:

```bash
python3 -m http.server -d site 4173
```

> چون داده‌ها با `fetch` بارگذاری می‌شوند، باز کردن مستقیم `index.html` با `file://` کار نمی‌کند؛ از سرور محلی استفاده کنید.

## استقرار روی GitHub Pages

`.github/workflows/pages.yml` با هر push روی `main` که `site/**` را تغییر دهد اجرا می‌شود:

1. اعتبارسنجی: `node --check` روی JS، پارس شدن JSONها، و بررسی اینکه هر اسکیل/دستور/agent ارجاع‌داده‌شده در `playbooks.json` در `data.json` وجود دارد.
2. آپلود پوشهٔ `site/` به‌عنوان artifact و انتشار با `actions/deploy-pages`.

تنظیم لازم در ریپو: **Settings → Pages → Source: GitHub Actions**.
دامنهٔ اختصاصی (اختیاری): یک repository variable به نام `PAGES_CUSTOM_DOMAIN` بسازید؛ ورک‌فلو فایل `CNAME` را خودکار اضافه می‌کند.

## ساختار

```
site/
├── index.html              # پوستهٔ اپ (هیرو، ویوها، پالت، tabbar موبایل)
├── manifest.webmanifest    # PWA: نصب‌پذیر
├── sw.js                   # سرویس‌ورکر: کش داده + کارکرد آفلاین
├── serve.mjs               # سرور استاتیک بدون وابستگی (فقط برای توسعه)
├── assets/
│   ├── styles.css          # سیستم طراحی (کاغذ/جوهر + لهجهٔ نارنجی، تم روشن/تاریک، چاپ)
│   ├── app.js              # روتر هش‌محور، رندر ویوها، جست‌وجو، کپی، پالت
│   ├── data.json           # <تولیدشده> ۳۱۴ اسکیل + ۹۸ دستور + ۷۱ agent
│   ├── playbooks.json      # ۱۵ مسیر خدمت: مراحل، ابزار، پرامپت‌ها، تله‌ها
│   ├── favicon.svg
│   └── og.svg              # تصویر Open Graph
└── tools/
    └── gen-data.mjs        # بازتولید data.json از یک checkout از ECC
```

## بازتولید کاتالوگ

```bash
git clone --depth 1 https://github.com/affaan-m/ecc.git /tmp/ecc
node site/tools/gen-data.mjs --src /tmp/ecc
```

اسکریپت `name`/`description` را از frontmatter فایل‌های `skills/*/SKILL.md`، `commands/*.md` و `agents/*.md` می‌خواند.
ارجاع‌های نام در `playbooks.json` باید با همین نام‌ها تطبیق داشته باشند؛ ورک‌فلو Pages این را خودکار بررسی می‌کند.

## امکانات اپ

- **روتر هش‌محور** با ویوهای مستقل و لینک مستقیم: `#/services`، `#/s/website`، `#/library`، `#/install`
- **کتابخانهٔ کامل** با جست‌وجوی نرمال‌شده (ی/ک فارسی-عربی)، تب اسکیل/دستور/agent و فیلتر «فقط ابزارهای مسیرها»
- **پالت دستور** با `Ctrl/Cmd+K` یا `/` و پیمایش با کلید
- **کپی با یک کلیک** (clipboard + فالبک `execCommand`) برای نام‌ها، دستورها و پرامپت‌ها
- **PWA**: `manifest` + سرویس‌ورکر با استراتژی «شبکه اول» برای داده و «کش اول» برای دارایی‌ها
- **دسترسی‌پذیری**: RTL، فوکوس نمایان، `aria-current`، پرش به محتوا، `prefers-reduced-motion`
- **تم روشن/تاریک** با ذخیره در `localStorage` و به‌روزرسانی `theme-color`
- **چاپ / PDF** برای گرفتن چک‌لیست مسیر

## Agent Studio و Free Claude Code

صفحهٔ اصلی به داشبورد فارسی Agent Studio تبدیل شده است. مسیرهای ECC، کتابخانه، جست‌وجو و راهنمای نصب قبلی همچنان در دسترس‌اند. بخش «Free Claude Code» دستورهای شروع و لینک مستندات رسمی را نشان می‌دهد؛ این سایت استاتیک است و به خودی خود سرور FCC یا یک مدل هوش مصنوعی را اجرا نمی‌کند. سورس FCC به صورت snapshot در `../free-claude-code/` قرار دارد و تحت AGPL-3.0-only منتشر شده است.

## حساب و فضای شخصی

بخش `#/workspace` از Supabase Auth و جدول `workspace_notes` استفاده می‌کند. کلید publishable در `src/workspace.js` عمداً عمومی است؛ محرمانگی به سیاست‌های RLS در `db/001_workspace_notes.sql` وابسته است. رمز کاربر و توکن در مخزن ذخیره نمی‌شوند. سرویس Supabase برای این استودیو مستقل است. برای بازسازی فایل مرورگر پس از تغییر سورس: `cd site && npm ci && npm run build:workspace`. مجوز SDK در `LICENSE-SUPABASE` است.

## اجرای ایجنت روی دستگاه شخصی

FCC Admin طبق طراحی بالادستی فقط محلی است و نباید مستقیماً به اینترنت باز شود. پس از نصب FCC، تنظیم provider و نصب Codex، `fcc-server` را در دستگاه خود اجرا کنید. سپس در ترمینالی دیگر:

```bash
node site/serve.mjs --host 127.0.0.1 --port 4173 --fcc-local
```

آدرس چاپ‌شده را **در مرورگر همان دستگاه** باز و به Free Claude Code بروید. در صورت تغییر پورت FCC از `--fcc-port` استفاده کنید (پیش‌فرض 8082). پروکسی محدود فقط با انتخاب صریح این گزینه و اتصال loopback کار می‌کند و قابلیت اجرای دستور و تغییر فایل دارد؛ این حالت را در محیط اشتراکی یا برای کاربران نامطمئن اجرا نکنید. درخواست‌های تأیید، انتخاب مدل و امکانات کامل در Admin خود FCC انجام می‌شوند. نسخه Vercel فقط فضای کار و راهنما را ارائه می‌دهد و نمی‌تواند به FCC محلی کاربر وصل شود؛ برای اجرای ابری به طراحی ایزوله و احراز هویت جداگانه نیاز است.
