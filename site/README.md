# ECC Playbook — سایت راهنمای «چه چیزی برای چه کاری»

سایتی فارسی و تک‌صفحه‌ای که کاتالوگ ریپوی [affaan-m/ecc](https://github.com/affaan-m/ecc) را به **نیاز واقعی بازدیدکننده** نگاشت می‌کند:
برای هر خدمت (ساخت سایت، داشبورد، API، امنیت، کارایی، ایجنت، …) مسیر گام‌به‌گام، اسکیل‌ها/دستورها/agentهای مربوطه و **پرامپت‌های آماده برای کپی** را نشان می‌دهد.

بدون وابستگی، بدون build: فقط سه فایل CSS/JS و یک صفحهٔ HTML.

## اجرا

```bash
node site/serve.mjs              # http://localhost:4173
node site/serve.mjs --port 8080  # پورت دلخواه
```

یا با هر سرور استاتیک دیگر؛ کافی است `site/` ریشه باشد:

```bash
python3 -m http.server -d site 4173
```

## ساختار

```
site/
├── index.html            # ساختار صفحه (RTL، فارسی)
├── serve.mjs             # سرور استاتیک بدون وابستگی (برای پیش‌نمایش)
├── assets/
│   ├── styles.css        # طراحی: کاغذ گرم + جوهر تیره + لهجهٔ نارنجی، تم روشن/تاریک
│   ├── data.js           # <auto> کاتالوگ ۳۱۴ اسکیل، ۹۸ دستور، ۷۱ agent — تولیدشده
│   ├── playbooks.js      # ۱۵ مسیر خدمت: مراحل، ابزار، پرامپت‌ها، تله‌ها
│   └── app.js            # رندر، جست‌وجو، فیلتر، کپی، پالت دستور، تم
└── tools/
    └── gen-data.mjs      # تولید دوبارهٔ data.js از یک checkout از ECC
```

## بازتولید کاتالوگ

`data.js` را از کد اصلی بسازید (نه دستی):

```bash
git clone --depth 1 https://github.com/affaan-m/ecc.git /tmp/ecc
node site/tools/gen-data.mjs --src /tmp/ecc --out site/assets/data.js
```

اسکریپت `name` و `description` را از frontmatter فایل‌های `skills/*/SKILL.md`، `commands/*.md` و `agents/*.md` می‌خواند.
هر ورودی مسیرها (مثل `"skills": ["react-patterns", …]`) باید با همین نام‌ها تطبیق داشته باشد؛ اگر تطبیق نداشته باشد، در UI با خط‌خوردگی و `title` نشان داده می‌شود.

## ویژگی‌ها

| ویژگی | توضیح |
|---|---|
| ۱۵ مسیر خدمت | سایت، وب‌اپ/داشبورد، API، معماری/ریفکتور، موبایل، ایجنت و RAG، تست/TDD، امنیت، کارایی، سئو/محتوا، دواپس، دیتابیس، آنبوردینگ، داده/ML، نصب ECC |
| جعبه‌ابزار هر مسیر | اسکیل / دستور / agent با کلیک = کپی نام، و دستور نصب آماده |
| پرامپت‌های آماده | ۳۵+ پرامپت با جای‌نگهدار `{…}`؛ کپی تک‌تک یا همه با هم |
| کتابخانهٔ کامل | ۴۸۳ جزء با جست‌وجوی زنده و تب‌ها |
| پالت دستور | `Ctrl/Cmd+K` یا `/` برای جست‌وجو و کپی سریع |
| لینک‌پذیری | `#service=website` مسیر را مستقیم باز می‌کند |
| دسترسی‌پذیری | RTL، کنتراست AA، فوکوس نمایان، احترام به `prefers-reduced-motion`، پرش به محتوا |
| تم | روشن/تاریک با ذخیره در `localStorage` |
| چاپ | استایل چاپ برای گرفتن چک‌لیست مسیر |
